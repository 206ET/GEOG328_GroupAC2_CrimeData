About This Project

The Seattle Crime Explorer is an interactive mapping application designed to make public safety data more accessible to Seattle residents and decision-makers. With recent increases in certain types of crime, understanding where and when incidents occur is crucial for community safety planning, urban policy, and personal security decisions.

This application visualizes over 64,000 crime incidents reported to the Seattle Police Department, allowing users to explore patterns and trends across the city's neighborhoods and precincts. By combining interactive filtering with dual visualization modes—a heatmap for identifying geographic hotspots and point markers for examining individual incidents—the Explorer enables data-driven insights into public safety.

Key Features

  • Crime Type Filtering: Isolate violent crimes, property crimes, or other offenses to see category-specific patterns
  • Neighborhood Analysis: Compare crime rates and patterns across Seattle's 43+ distinct neighborhoods
  • Temporal Filtering: Select custom date ranges to analyze seasonal trends, recent hotspots, or historical patterns
  • Dual Visualization: Toggle between heatmap (density view) and point markers (incident detail view) by zooming in and out
  • Interactive Details: Click any crime marker to view specific incident information including report number, date/time, neighborhood, and precinct
  • Real-time Statistics: Automatic calculation of filtered crime counts, category breakdowns, and percentage distributions

Intended Audience

  • Seattle residents concerned about neighborhood safety
  • Prospective residents evaluating neighborhoods before moving to Seattle
  • Community organizations and neighborhood watch groups developing safety initiatives
  • Urban planners and policymakers allocating resources and developing crime prevention strategies
  • Real estate professionals and renters/buyers making location decisions

Data & Methods

Dataset Description

This application integrates three primary datasets to provide comprehensive crime analysis:

1. Seattle Police Department Crime Data (2008–Present)

Source: data.seattle.gov
This dataset contains all recorded crimes reported to the Seattle Police Department from January 2008 through the present day. The current dataset includes 64,593 crime incidents with the following attributes:

  • Report Number: Unique identifier for each incident
  • Offense Date & Time: When the crime occurred (in 24-hour format)
  • Report Date & Time: When the crime was reported
  • Offense Category: Primary classification (Violent Crime, Property Crime, or All Other)
  • Offense Sub-Category: Detailed crime type (e.g., Burglary, Larceny-Theft, Assault)
  • Location Data: Geographic coordinates (longitude/latitude), neighborhood, precinct, sector, and beat

2. Seattle Neighborhood Boundaries

Source: SeattleCityGIS Open Data
This geographic dataset provides polygon boundaries for all 43 neighborhood areas in Seattle, enabling spatial analysis and allowing crime incidents to be associated with their respective neighborhoods.

3. Supplementary Crime Dataset

Source: Kaggle
This dataset provides additional records of Seattle crime incidents with location coordinates, used to supplement and validate the primary SPD dataset.

Data Processing & Methodology

Data Integration: The datasets were merged using spatial joins and common identifiers. Geographic coordinates were standardized and validated against the neighborhood boundaries to ensure accurate spatial association.

Date/Time Normalization: Offense dates were parsed from multiple formats (ISO 8601, MM/DD/YYYY, and text-based formats) and converted to Unix timestamps (milliseconds since epoch) to enable reliable temporal filtering and analysis.

Crime Categorization: Crimes are classified into three primary categories based on SPD classifications:

  • Violent Crime (5.4%): Includes homicides, assaults, robberies, and rape (3,479 incidents)
  • Property Crime (55.7%): Includes burglary, larceny-theft, and motor vehicle theft (35,972 incidents)
  • All Other (38.9%): Includes narcotics, fraud, trespass, and other offenses (25,142 incidents)

Visualization Design

Heatmap Layer: Displays kernel density estimation of crime incidents, with intensity and radius interpolated based on zoom level. This visualization is optimized for identifying geographic hotspots and patterns at lower zoom levels (10–14).

Point Markers: Individual crime incidents rendered as circles, color-coded by offense category. Circle size and opacity scale with zoom level to prevent marker congestion while maintaining visibility of incident density. The marker-to-heatmap transition is automatic as users zoom in and out.

Color Coding:

  • Red (#b91c1c): Violent crimes
  • Blue (#1d4ed8): Property crimes
  • Gray (#9ca3af): All other offenses

Key Statistics

  • Total Crimes: 64,593 incidents
  • Most Common Crime Type: Larceny-Theft (22,653 incidents, 35.1%)
  • Neighborhoods with Highest Crime: Capitol Hill (8.4%), Downtown Commercial (5.6%), Queen Anne (5.4%)
  • Precinct with Highest Crime: North Precinct (30.6% of incidents)
  • Temporal Coverage: 2008–Present (most recent data: November 2024)

Technical Stack

  • Frontend Framework: Mapbox GL JS v3.2.0 for interactive web mapping
  • Data Format: GeoJSON for efficient client-side rendering and filtering
  • Styling: Custom CSS with responsive design for desktop and mobile devices
  • Interactivity: Client-side filtering for real-time performance (no server requests required after initial load)

Limitations & Considerations

  • Reporting Bias: Crime data reflects reported incidents only. Many crimes go unreported, and reporting rates vary by neighborhood and offense type.
  • Data Completeness: Some older records may have incomplete or missing geographic coordinates, limiting their inclusion in spatial analysis.
  • Temporal Lag: Crime data is typically reported within hours to days of occurrence, but official statistics may lag by several weeks.
  • Privacy Considerations: While crime data is public, this tool is designed to identify patterns and trends rather than pinpoint specific addresses or individuals.
